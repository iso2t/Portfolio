# Heavy Inventories API

Integrate item weight, inventories, containers, and HUD behavior with your mod.
These guides cover **4.263.0.0-rc.2 for Minecraft 26.3**, matching the
[developer guide](/heavy-inventories/developers).

Start with [getting started](/heavy-inventories/api/getting-started) for dependencies
and plugin registration, then choose the integration you need:

- [Weight queries](/heavy-inventories/api/weight-queries)
- [Inventories and capacity](/heavy-inventories/api/inventories-and-capacity)
- [Container contents](/heavy-inventories/api/container-contents)
- [HUD](/heavy-inventories/api/hud)
- [Notifications](/heavy-inventories/api/notifications)
- [Testing](/heavy-inventories/api/testing)
