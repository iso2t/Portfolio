# Easy Config

A class-based config API and in-game config screen for Minecraft mods.

Easy Config provides one configuration API for Fabric and NeoForge, with in-game
screens, tabs for multiple configs, Fabric Mod Menu integration, and lower-level
APIs for custom loading, saving, and metadata.

## For players

Mods that use Easy Config can expose their settings in game. On NeoForge, use the
native mod-list config button. On Fabric, install Mod Menu to access those screens.
See [installation](/easy-config/installation).

## For developers

Start with [dependencies](/easy-config/dependencies), then
[create a config](/easy-config/creating-a-config). The mod artifacts include the API;
the standalone API is for Java consumers that do not need Minecraft screens.
