# Configuring Sverve

Sverve uses [Easy Config](/easy-config) for its survival settings. The current
source branch builds a server-side TOML config named `sverve-survival`.

After the mod initializes, look for `config/sverve-survival-server.toml` in the
server or game instance. Edit the server's config when configuring multiplayer.

## Settings groups

| Section | What it configures |
| --- | --- |
| `temperature` | Temperature mechanics |
| `moisture` | Moisture mechanics |
| `thirst` | Hydration and thirst mechanics |
| `heatSources` | Environmental sources of heat |
| `heavyInventories` | Heavy Inventories load and thirst integration |

Use the generated comments and allowed ranges alongside each setting. Settings
can differ between releases, so use the file generated by your installed version.

The registered config screen is titled **Survival**. See
[Easy Config installation](/easy-config/installation) for accessing mod config
screens on Fabric and NeoForge.

For the implementation and current defaults, see
[`SurvivalConfig`](https://github.com/iso2t/Sverve/blob/master/common/src/main/java/com/iso2t/sverve/config/SurvivalConfig.java).
